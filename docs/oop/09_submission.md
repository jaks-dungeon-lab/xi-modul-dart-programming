# Tugas Penilaian: Turn-Based Game

Untuk menguji penguasaanmu terhadap logika pemrograman (Computational Thinking) dan struktur Object-Oriented Programming (OOP), kamu diwajibkan untuk mengerjakan sebuah proyek simulasi pertarungan **Turn-Based Game** sederhana berbasis teks terminal.

Di dalam game ini, seorang pahlawan (Hero) akan bertarung melawan musuh (Monster) secara bergantian hingga salah satunya gugur.

## Instruksi Pengerjaan

Kamu dituntut untuk merancang aplikasi ini menggunakan pilar-pilar OOP yang telah dipelajari:

1. Memisahkan *Class* sebagai cetakan karakter dan *Method* sebagai aksi menyerang.
2. Memanfaatkan **Inheritance** untuk membuat berbagai kelas karakter khusus (seperti class `Mage` atau `Healer` yang diturunkan dari class `Karakter`).
3. Membangun *Game Loop* yang berjalan secara interaktif menggunakan perulangan `while` dan logika input.
