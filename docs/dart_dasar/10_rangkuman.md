# Rangkuman Dart Dasar

Selamat! Berikut adalah ringkasan dari urutan yang sudah kita pelajari:

1. **Comments**: Catatan tak kasat mata (`//` atau `/* */`) untuk pembuat kode.
2. **Variables & Constants**: Wadah penyimpan data (kotak kardus). `var` untuk variabel biasa yang bisa ditebak. `final` dan `const` digunakan untuk kotak data yang dilakban mati.
3. **Built-in Types**: Bentuk spesifik wadah (`int`, `double`, `String`, `bool`).
4. **Operators**: Alat penghitung dan pembanding data (`+`, `-`, `==`, `>`).
5. **Exceptions**: Sabuk pengaman program (`try-catch`) agar aplikasi tidak *crash* jika menemukan error fatal (seperti angka dibagi nol).
6. **Functions**: Mesin blok kode (seperti *juicer*) yang memiliki data masuk (*parameter*) dan nilai keluar (*return*).
7. **Variable Scope**: Aturan ruangan tentang di mana saja sebuah variabel boleh dikenali (lingkup global vs lokal).
8. **Null Safety**: Aturan ketat Dart untuk mencegah kita memakai variabel yang isinya tak bernilai (`null`). Gunakan `?` jika variabel sengaja boleh kosong.
