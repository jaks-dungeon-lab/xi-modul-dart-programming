# Rangkuman Paruh Pertama

Selamat! Kamu telah menyelesaikan tiga bab utama dalam bahasa pemrograman Dart: **Dart Dasar**, **Control Flow**, dan **OOP Dasar**. Berikut adalah intisari dari semua materi yang sudah kamu pelajari.

## 1. Dart Dasar

Pada bagian ini, kita mempelajari pondasi awal dari bahasa Dart.

- **Variabel dan Tipe Data**: Kita menggunakan variabel untuk menyimpan nilai. Dart memiliki beberapa tipe data utama seperti **int** (angka bulat), **double** (angka desimal), **String** (teks), dan **bool** (benar/salah).
- **Kata Kunci**: Gunakan **var** untuk variabel yang bisa diubah, dan **final** atau **const** untuk nilai yang tidak boleh berubah.
- **Fungsi**: Blok kode yang dirancang untuk melakukan tugas tertentu. Fungsi bisa menerima **parameter** sebagai input dan memberikan **return** sebagai hasil keluaran.
- **Null Safety**: Fitur pelindung dari Dart untuk mencegah *error* akibat variabel kosong. Kita menggunakan tanda **?** untuk mengizinkan variabel bernilai kosong (null).

## 2. Control Flow (Alur Kontrol)

Bagian ini mengajarkan cara mengatur arah berjalannya program.

- **Percabangan**: Menggunakan **if**, **else if**, dan **else** untuk membuat program mengambil keputusan berdasarkan kondisi tertentu.
- **Perulangan**: Menggunakan **for**, **while**, atau **do-while** untuk menjalankan baris kode yang sama berkali-kali tanpa harus menulis ulang.

## 3. OOP Dasar (Object-Oriented Programming)

Di sini kita belajar memodelkan program seperti dunia nyata.

- **Class dan Object**: **Class** adalah cetakan biru (blueprint), sedangkan **Object** adalah hasil nyata dari cetakan tersebut.
- **Properties dan Method**: **Properties** adalah ciri-ciri atau atribut dari sebuah objek (misal: warna, merk), sedangkan **Method** adalah tindakan yang bisa dilakukan oleh objek tersebut (misal: berjalan, berhenti).
- **Constructor**: Fungsi khusus di dalam class yang pertama kali dijalankan saat objek baru dibuat, biasanya digunakan untuk memberikan nilai awal pada *properties*.
- **Inheritance (Pewarisan)**: Menggunakan kata kunci **extends** agar sebuah class anak dapat mewarisi *properties* dan *method* dari class induknya.
